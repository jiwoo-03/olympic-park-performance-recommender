# 전처리·EDA 단계 리포트

작성일: 2026-11-09

워크플로우 문서 4.3 "전처리·EDA" 단계의 완료 기준(`performances` 정제 테이블과 EDA 결과)에
따라 작성한다. 입력은 `pipeline/collection/REPORT.md`에서 수집한 raw 데이터(KOPIS 812건
상세, 문체부 통합 공연정보 중 한국체육산업개발 필터 2,780건)다.

## 실행 순서

```bash
cd pipeline/preprocessing
pip install -r requirements.txt
python run_all.py   # match_performances.py → normalize_and_clean.py → eda.py
```

## 1. 데이터 정제: 대관 운영 레코드 제외

문체부 통합 공연정보 API가 돌려준 "한국체육산업개발" 행 2,780건 중 **819건(29%)은 실제
공연이 아니라 "준비대관"(433), "예약완료"(330), "철거대관"(47) 같은 시설 운영 상태
레코드**였다. 공연명 키워드로 걸러내고 남은 **1,961건**을 매칭·EDA 대상으로 삼았다.

## 2. KSPO ↔ KOPIS 매칭

- 매칭 키: 공연명(공백·특수문자·연도 숫자 제거) 완전일치 → 실패 시 rapidfuzz 유사도(≥70) 상위
  5개 후보 → 공연 기간 겹침으로 교차 검증.
- 연도 숫자를 정규화 단계에서 제거한 이유: 한국체육산업개발 쪽 제목은 "2026 ○○ 콘서트
  〈2026 ○○〉"처럼 연도를 중복 표기하는 경우가 많아 그대로 두면 문자열 유사도가 떨어진다.
  연도가 틀려서 생기는 오매칭은 뒤따르는 기간 겹침 검증이 걸러준다.
- 유사도 상위 1개만 보지 않고 5개까지 본 이유: "호두까기인형"처럼 매년 재공연되는 제목은
  작년 레코드가 올해 레코드보다 문자열이 더 비슷하게 나올 수 있어, 상위 1개만 보면 날짜가
  맞는 올해 레코드를 놓친다.

**매칭 결과**

| 상태 | 건수 | 비율 |
| --- | --- | --- |
| matched (장르·출연진 등 확보) | 651 | 33.2% |
| title_only_mismatch_period (제목만 비슷, 기간 불일치 → 수기 확인 대상) | 100 | 5.1% |
| unmatched (KOPIS에 없음) | 1,210 | 61.7% |

**매칭률이 낮은 이유** (단순 버그가 아니라 구조적인 커버리지 차이로 확인됨):

1. KSPO 원본은 2010~2027년 데이터를 포함하지만, 이번 수집은 KOPIS 올림픽공원 공연 821건
   (마찬가지로 2013년부터)만 가져왔다 — 두 소스의 기간 자체는 거의 겹친다.
2. KOPIS는 "공연예술"(티켓 판매가 되는 공연)만 다룬다. KSPO 쪽에는 스포츠 경기, 전시, 사내
   행사, 대관 세미나처럼 애초에 KOPIS에 등록되지 않는 행사가 섞여 있어 이 부분은 구조적으로
   매칭될 수 없다 — 워크플로우 문서 7장이 예상한 리스크("공원 내 무료 행사·전시까지 대상
   확대")와 일치한다.
3. unmatched 1,210건은 수기 라벨링 대상으로 남겨뒀다(장르 = "미분류").

## 3. 장르·요금·관람연령 정규화

- 장르: KOPIS 세부 장르(`genrenm`) + 제목 키워드("페스티벌", "어린이" 등)를 6종으로 통일.
  KOPIS 매칭이 안 된 공연은 "미분류"로 남겨 임의로 추정하지 않았다.
- 요금: `pcseguidance` 문자열("SR석 154,000원, R석 143,000원")에서 숫자를 모두 뽑아
  최저가/최고가로 정규화. 매칭된 공연의 97.5%에서 파싱 성공.
- 관람연령: `prfage` 문자열("만 8세 이상")에서 최소 나이 추출, "전체관람가"는 0세. 매칭된
  공연의 94.3%에서 파싱 성공.

미분류가 많다는 것은 곧 KOPIS 매칭률(33%)의 반대쪽 숫자다 — 추천 모델 1단계(콘텐츠
기반 유사도)에서 장르 커버리지를 늘리려면 매칭률을 올리는 게 최우선 과제다. 다만
KOPIS 매칭이 안 된 공연 중에서도 제목에 "콘서트"가 명시된 건 `classify_genre()`의
미매칭 전용 키워드 폴백으로 구제한다(2026-11-12, `tasks/verification.md` 참고) —
그래서 미분류 건수가 1,247 → 772로 줄었다.

## 4. EDA 결과

차트는 `figures/`에 저장했다.

- **공연장별 공연 수** (`venue_counts.png`): 올림픽홀(451)·체조경기장/KSPO DOME 계열(143+41+29+25=238)·
  핸드볼경기장(149)·우리금융아트홀 계열(104+51=155) 순. **같은 공연장이 "올림픽홀" / "올림픽공원
  올림픽홀", "KSPO DOME" / "KSPO DOME(체조경기장)" / "올림픽공원 체조경기장"처럼 여러 표기로
  흩어져 있다** — 다음 단계(추천 모델)에서 쓰기 전에 장소명 정규화 매핑 테이블이 필요하다.
- **연도별 공연 수** (`yearly_counts.png`): 2011~2013년 150~220건으로 피크, **2020년 18건으로
  급감**(코로나19 영향으로 추정) 후 2021~2022년부터 서서히 회복, 2025~2026년 125~127건으로
  안정화. 취향 학습에 쓸 과거 데이터는 사실상 2021년 이후가 더 대표성이 있다.
- **요일별 공연 패턴** (`weekday_counts.png`): 토요일 940건, 금요일 494건으로 주말에 압도적으로
  몰려있고 화요일이 70건으로 가장 적다. 주차 혼잡 예보 모델(6장)에서 요일 변수는 중요한
  신호가 될 것으로 보인다.
- **요금 분포** (`price_distribution.png`): 매칭된 공연의 32.4%만 요금 정보 확인 가능(KOPIS
  매칭 공연에 한정). 평균 최저가 114,231원, 평균 최고가 141,872원 — 대형 콘서트 위주라
  일반 공연장 대비 가격대가 높다.

## 5. 남은 리스크·다음 단계

1. **매칭률 33% 개선**: unmatched 1,210건 중 실제로는 KOPIS에 존재하지만 이번 수집(812건)에
   빠진 경우가 있는지 확인 필요. KOPIS 상세 수집 실패 9건(`pipeline/collection`에 기록)부터
   재시도.
2. **장소명 정규화**: EDA에서 드러난 변형 표기들을 표준 5개 공연장명(KSPO DOME, 우리금융아트홀,
   핸드볼경기장, 88잔디마당, 수변무대)으로 매핑하는 테이블을 추천 모델 단계 전에 만들어야 한다.
3. **올림픽공원 대관정보·주차 API**는 여전히 실패 상태라(`pipeline/collection/REPORT.md` 참고)
   주차 혼잡 예보 모델은 착수할 수 없다 — 4주차 전 해결 필요.
4. **미분류 1,243건**: 장르를 수기로 라벨링하거나, 제목 키워드 규칙을 더 정교하게 다듬어
   커버리지를 늘릴 여지가 있다.
