# 작업 기록 (`tasks/`)

- `todo.md` — 작업을 시작하기 전에 적는 계획. 끝나면 체크하거나 지운다.
- `verification.md` — 작업을 마친 뒤 거친 검증(무엇을·어떻게 확인했는지, 통과/실패) 기록.
- `lessons.md` — 사용자가 수정을 지적했거나 verification.md에서 실수가 드러났을 때,
  그 패턴(무엇을 왜 고쳤는지)을 기록. 다음에 같은 실수를 반복하지 않는 데 쓴다.
- `session-log.md` — 세션별 한 일·막힌 점·다음 할 일. 날짜 제목(`## YYYY-MM-DD`)으로 구분.
